# Technical SEO Audit — datadecision.consulting

Date: 1 September 2026. Environment: local repo `datadecision-site` @ `edab826` + live-site verification. Baseline build: PASS (`npm run build`, 71 HTML files). Baseline validation: PASS (`npm run validate` — routes, links, metadata, schema, claim guardrails all green).

## 1. Stack (verified)

- Astro 7 static output; `trailingSlash: 'always'`, `build.format: 'directory'`; GitHub Pages via `.github/workflows/astro.yml` (Node 22) from `master`; custom domain via `public/CNAME`.
- No client framework; vanilla JS; self-hosted fonts (fontsource); single CSS file; inline critical scripts. Page-weight profile is inherently LCP-friendly.
