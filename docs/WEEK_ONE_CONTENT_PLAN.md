# Week-one organic content plan — capacity up to 20 artifacts

All 20 may ship in the first week only when the individual release gate passes. The plan is a capacity map, not a quota. No artifact ships with empty research, invented results or a demonstration label applied to non-demonstration content.

## Universal release gate

Every artifact must have:

- a named owner and truthful authorship;
- a published and updated date;
- primary sources for volatile technical claims;
- original analysis, a reusable artifact or a genuine dataset;
- internal methodology and service links where relevant;
- visible limitations and sample/window fields for any result;
- `DEMONSTRATION RUN` only for genuine public-data research or DataDecision self-measurement;
- completed editorial, accessibility, link, claim and responsive review.
