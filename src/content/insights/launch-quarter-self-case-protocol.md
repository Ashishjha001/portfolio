Every launch claims momentum. Few launches can show the baseline they are measuring momentum against. The protocol below is how Data Decision Consulting publishes its own launch evidence, and it is reusable for any product or feature launch.

## The pre-committed frame

Write and publish these before observing outcomes:

| Field        | Commitment                                                                       |
| ------------ | -------------------------------------------------------------------------------- |
| Metrics      | A short, named list (visibility baseline, referrals, demo requests, CRM records) |
| Windows      | Day 0 baseline; 30/60/90-day observations                                        |
| Sample       | Query frame, surfaces, pages and denominators                                    |
| Method       | Version and link, e.g. [methodology v0.3](/methodology/)                         |
| Null results | Stated in advance as publishable                                                 |

Publishing the frame first is the entire trick. It converts later reporting from selection into comparison.

## Day 0: the baseline

Record the starting state with dates and denominators: visibility runs completed, referral counts, demo requests, CRM records. Store the raw values privately and publish the summary. The [visibility baseline method](/insights/build-ai-visibility-baseline/) defines the observation format.

## Days 30, 60, 90: comparisons

Each observation reports the same metrics, the same windows, and a delta against day 0. Report [null and negative results](/insights/small-conversion-samples-inference/) with the same prominence as wins. Label anything modelled, thresholded or sampled.

## Rules that keep the self-case honest

- The frame is written before day 0 and never edited retroactively; changes create a new frame version.
- Every claim links to its observation: date, window, sample, method.
- No metric joins the list after results are known.
- A third party should be able to rerun the observation from the published method and reach the same numbers.

## Why this matters commercially

A launch that can show a pre-committed frame, dated baselines and null results is more persuasive than one showing only highlights. The discipline is the differentiator: it demonstrates exactly how client evidence will be treated.
